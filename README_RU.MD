# SimpleCode
Библиотека для Arduino, которая делает код короче и чище. Она заменяет длинные блоки кода, функции устранения дребезга контактов (дебаунс) и таймеры на простые и понятные функции.

## Особенности
* **Явная инициализация:** Настройка пинов вынесена в отдельные методы `.begin()` для лучшего контроля и соответствия стандартам Arduino.
* **Массовая настройка пинов:** Легко настраивайте целый диапазон идущих подряд пинов с помощью `regPins()` или произвольный массив пинов через `regPinsArray()`.
* **Никаких `delay()`:** Антидребезг кнопок, мигание светодиодов и таймеры ожидания работают асинхронно на основе `millis()`, вообще не замораживая основной цикл программы.
* **Продвинутое управление LED:** Простые методы (`on()`, `off()`, `toggle()`), а также мощная функция `blink()` с раздельной настройкой времени работы и паузы.
* **Универсальная работа с переключателями:** Библиотека разделена на специальные методы под разное железо: `isPressed`/`wasPressed` для обычных тактовых кнопок и `isOn`/`wasFlippedOn` для фиксируемых тумблеров.

## Установка

1. Скачайте папку с библиотекой в виде **ZIP-архива**.
2. Откройте **Arduino IDE**.
3. Перейдите в меню: **Скетч** -> **Подключить библиотеку** -> **Добавить .ZIP библиотеку...** (Sketch -> Include Library -> Add .ZIP Library...).
4. Выберите скачанный архив. Библиотека готова к использованию!

## Руководство (Функции и Классы)

### Глобальные функции (Для настройки и времени)
* **`regPins(firstPin, lastPin, mode)`**  
  Настраивает диапазон идущих подряд пинов от начального до конечного.
  * `firstPin` *(uint8_t)*: Первый пин в диапазоне.
  * `lastPin` *(uint8_t)*: Последний пин в диапазоне.
  * `mode` *(byte)*: Режим пина (`INPUT`, `INPUT_PULLUP` или `OUTPUT`).
* **`regPinsArray(pinsArray, arraySize, mode)`**  
  Настраивает массив пинов, которые могут идти в любом случайном порядке.
  * `pinsArray` *(const uint8_t[])*: Ваш массив с номерами пинов.
  * `arraySize` *(byte)*: Общее количество пинов в массиве (используйте `sizeof(pinsArray) / sizeof(pinsArray)`).
  * `mode` *(byte)*: Режим пина (`INPUT`, `INPUT_PULLUP` или `OUTPUT`).
* **`wait(ms)`**  
  Альтернатива функции `delay()`, которая не замораживает код. Возвращает `true`, когда время ожидания подошло к концу.
  * `ms` *(unsigned long)*: Время ожидания в миллисекундах.

### Класс: Switch
Создан как для тактовых кнопок (без фиксации), так и для физических тумблеров (использует внутреннюю подтяжку `INPUT_PULLUP`).

* **`Switch(pin, debounceDelay = 50, clickTimeout = 400)`**  
  Конструктор для создания объекта кнопки/переключателя.
  * `debounceDelay`: Время фильтрации дребезга в миллисекундах (по умолчанию 50 мс).
  * `clickTimeout`: Максимальное время удержания в мс, при котором нажатие засчитается как быстрый клик для `wasPressed()` (по умолчанию 400 мс).
* **`begin()`** — Настраивает пин как `INPUT_PULLUP`. Обязательно вызывать внутри `setup()`.

#### Методы для тактовых кнопок (без фиксации):
* **`isPressed()`** — Возвращает `true` всё время, пока кнопка удерживается нажатой и превышен таймаут клика (зажимание кнопки).
* **`isReleased()`** — Возвращает `true` всё время, пока кнопка отпущена.
* **`wasPressed()`** — Возвращает `true` строго один раз в момент отпускания кнопки, если она удерживалась меньше времени `clickTimeout` (фиксирует короткий клик).
* **`wasReleased()`** — Возвращает `true` строго один раз в самый первый момент, когда кнопку отпустили.

#### Методы для физических тумблеров (выключателей с фиксацией):
* **`wasFlippedOn()`** — Возвращает `true` строго один раз в момент переключения тумблера в положение **ON**.
* **`wasFlippedOff()`** — Возвращает `true` строго один раз в момент переключения тумблера в положение **OFF**.
* **`isOn()`** — Возвращает `true` всё время, пока тумблер находится в положении **ON**.
* **`isOff()`** — Возвращает `true` всё время, пока тумблер находится в положении **OFF**.

---

### Класс: LED
Используется для управления светодиодами без остановки основного цикла программы.

* **`LED(pin)`** — Конструктор для создания объекта светодиода на определенном пине.
* **`begin()`** — Настраивает пин как `OUTPUT`. Обязательно вызывать внутри `setup()`.
* **`on()`** — Включает светодиод. Сбрасывает текущее мигание, если оно было запущено.
* **`off()`** — Выключает светодиод. Сбрасывает текущее мигание.
* **`toggle()`** — Инвертирует состояние светодиода (включает, если был выключен, и выключает, если горел).
* **`blink(onTime, offTime)`** — Запускает асинхронное мигание внутри `loop()`.
  * `onTime` *(unsigned long)*: Время работы светодиода (мс).
  * `offTime` *(unsigned long)*: Время паузы (мс).
* **`stopBlink()`** — Останавливает мигание светодиода и принудительно гасит его.

## Пример: Управление тумблером
Этот пример показывает, как использовать библиотеку с физическим тумблером для управления светодиодом и вывода статуса через неблокирующие таймеры.

```cpp
#include "SimpleCode.h"

// Примечание: Этот пример разработан для физического тумблера (с фиксацией)

// Настраиваем тумблер на 2-м пине
Switch toggleSwitch(2);

// Настраиваем светодиод на 13-м пине
LED testLed(13);

void setup() {
  // Открываем монитор порта на скорости 9600
  Serial.begin(9600);
  
  // Инициализируем тумблер и светодиод
  toggleSwitch.begin();
  testLed.begin();
  
  Serial.println("Physical Toggle Switch Example Started!");

  // Проверяем положение тумблера прямо при старте платы
  if (toggleSwitch.isOn()) {
    Serial.println("Startup: Switch is already ON");
    testLed.on(); // Включаем светодиод, если тумблер замкнут
  } else {
    Serial.println("Startup: Switch is already OFF");
    testLed.off(); // Выключаем светодиод, если тумблер разомкнут
  }
}

void loop() {
  // Срабатывает ровно ОДИН РАЗ при переключении тумблера в положение ON
  if (toggleSwitch.wasFlippedOn()) {
    testLed.on();
    Serial.println("Event: Switch flipped -> ON");
  }

  // Срабатывает ровно ОДИН РАЗ при переключении тумблера в положение OFF
  if (toggleSwitch.wasFlippedOff()) {
    testLed.off();
    Serial.println("Event: Switch flipped -> OFF");
  }

  // Постоянная проверка текущего положения тумблера
  if (toggleSwitch.isOn()) {
    // Выводим текст каждые 2 секунды, не затормаживая код
    if (wait(2000)) {
      Serial.println("Toggle is ON");
    }
  } else if (toggleSwitch.isOff()) {
    // Выводим текст каждые 2 секунды, не затормаживая код
    if (wait(2000)) {
      Serial.println("Toggle is OFF");
    }
  }
}
```
