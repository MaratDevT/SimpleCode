# SimpleCode

Библиотека для Arduino, которая делает код короче и чище, заменяя длинные блоки кода, фильтрацию дребезга контактов и таймеры на простые и понятные функции.

## Особенности
* **Явная и удобная инициализация**: Настройка пинов вынесена в понятные методы `.begin()`, что исключает скрытые процессы в конструкторе.
* **Массовая настройка пинов**: Возможность настроить диапазон пинов одной строчкой через `regPins()` или передать произвольный массив пинов через `regPinsArray()`.
* **Никаких delay()**: Антидребезг переключателей и мигание светодиодов работают асинхронно, не блокируя выполнение остального кода (на базе `millis()`).
* **Продвинутый контроль светодиодов**: Простые методы `on()`, `off()`, инверсия `toggle()` и мигание `blink()` с раздельным временем работы и паузы.
* **Универсальный класс Switch**: Благодаря разделению методов на непрерывную проверку состояния (`is...`) и фиксацию точечных событий (`was...`), класс идеально подходит как для тактовых кнопок, так и для фиксируемых тумблеров.

## Функции и Классы

### Глобальные функции (Для настройки в setup)

#### `regPins(firstPin, lastPin, mode)`
Конфигурирует непрерывный диапазон пинов от начального до конечного.
* `firstPin` (uint8_t): Первый пин диапазона.
* `lastPin` (uint8_t): Последний пин диапазона.
* `mode` (byte): Режим работы (`INPUT`, `INPUT_PULLUP` или `OUTPUT`).

#### `regPinsArray(pinsArray, arraySize, mode)`
Конфигурирует произвольный, не последовательный массив пинов.
* `pinsArray` (const uint8_t[]): Имя вашего массива с номерами пинов.
* `arraySize` (byte): Количество пинов в массиве (вычисляется как `sizeof(array) / sizeof(array[0])`).
* `mode` (byte): Режим работы (`INPUT`, `INPUT_PULLUP` или `OUTPUT`).

### Класс: Switch
Предназначен для работы с любыми переключателями: тактовыми кнопками, тумблерами и кнопками с фиксацией (с подтяжкой к `INPUT_PULLUP`).

#### `Switch(pin, debounceDelay = 50, clickTimeout = 400)`
Конструктор объекта переключателя.
* `pin` (uint8_t): Номер пина.
* `debounceDelay` (unsigned long): Время фильтрации дребезга контактов в миллисекундах. По умолчанию 50 мс.
* `clickTimeout` (unsigned long): Максимальное время удержания кнопки в миллисекундах, при котором нажатие всё ещё считается коротким кликом для метода `wasPressed()`. По умолчанию 400 мс.

#### `begin()`
Инициализирует пин в режиме `INPUT_PULLUP` и регистрирует его в системе. Обязательно вызывается в `setup()`.

#### `isPressed()`
Проверяет текущее состояние. Возвращает `true` **всё то время, пока тумблер включен** или кнопка удерживается нажатой.

#### `isReleased()`
Проверяет текущее состояние. Возвращает `true` **всё то время, пока тумблер выключен** или кнопка отпущена.

#### `wasPressed()`
Фиксирует событие клика. Возвращает `true` **строго один раз** в момент отпускания кнопки, если удержание длилось менее `clickTimeout` миллисекунд.

#### `wasReleased()`
Фиксирует событие размыкания. Возвращает `true` **строго один раз** в момент перехода тумблера/кнопки из нажатого состояния в отпущенное.

### Класс: LED
Используется для управления светодиодами без блокировки основного цикла программы.

#### `LED(pin)`
Конструктор объекта светодиода на указанном пине.

#### `begin()`
Инициализирует пин в режим `OUTPUT` и регистрирует его в системе. Обязательно вызывается в `setup()`.

#### `on()`
Включает светодиод (HIGH). Сбрасывает режим мигания.

#### `off()`
Выключает светодиод (LOW). Сбрасывает режим мигания.

#### `toggle()`
Инвертирует текущее состояние светодиода (включает, если был выключен, и наоборот).

#### `blink(onTime, offTime)`
Асинхронно мигает светодиодом внутри `loop()`.
* `onTime` (unsigned long): Время работы светодиода (включен) в миллисекундах.
* `offTime` (unsigned long): Время паузы светодиода (выключен) в миллисекундах.

#### `stopBlink()`
Принудительно останавливает мигание и гасит светодиод.

## Пример использования (Example)

```cpp
#include "SimpleCode.h"

// Создаем объект тумблера (Switch) на пине 2 и светодиода (LED) на пине 13
Switch myButton(2);
LED myLED(13);

void setup() {
  // Инициализируем устройства
  myButton.begin();
  myLED.begin();
}

void loop() {
  // Проверяем, включен ли тумблер (замкнут на GND)
  if (myButton.isPressed()) {
    // Асинхронно мигаем светодиодом без блокировки цикла loop
    myLED.blink(500, 500); 
  } else {
    // Когда тумблер выключается, мгновенно останавливаем мигание
    myLED.stopBlink(); 
  }
}
```

## Установка

### Способ 1: Через Менеджер библиотек Arduino (Рекомендуемый)
1. Откройте Arduino IDE.
2. Перейдите в меню **Скетч** -> **Подключить библиотеку** -> **Управлять библиотеками...**
3. Введите в поиске `SimpleCode` и нажмите **Установить**.

### Способ 2: Ручная установка
1. Скачайте данный репозиторий в виде ZIP-архива.
2. Распакуйте его в папку с библиотеками Arduino (обычно находится по пути: `Документы/Arduino/libraries/`).
3. Перезапустите Arduino IDE.
