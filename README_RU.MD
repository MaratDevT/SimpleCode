# SimpleCode

Библиотека для Arduino, которая делает код короче и чище, заменяя длинные блоки кода простыми и понятными функциями.

## 🚀 Особенности (Features)

* **Автоматическая настройка пинов для объектов (Ленивая инициализация):** Вам больше не нужно писать `pinMode()` в секции `setup()` при использовании объектов кнопок (`Button`) или светодиодов (`LED`). Библиотека автоматически настроит пины при инициализации.
* **Массовая ручная настройка:** Для обычных пинов вы можете легко настроить режим работы сразу для всей группы с помощью функций `regPins()` или `regPinsArray()`.
* **Работа без `delay()`:** Антидребезг кнопок и мигание светодиодов работают асинхронно и не блокируют выполнение основного кода, используя `millis()` «под капотом».
* **Управление диапазонами пинов:** Настраивайте целую цепочку пинов с помощью `regPins()` или кастомный массив пинов через `regPinsArray()` всего одной строчкой кода.
* **Базовый контроль светодиодов:** Простые и понятные методы для работы с LED: `on()`, `off()`, `toggle()` и неблокирующий `blink()`.
* **Совместимость:** Код написан на стандартных функциях Arduino. Полностью протестировано на классических платах AVR (Uno, Nano, Mega).

## 💻 Использование (Классы и Функции)

### Глобальные функции
Эти функции помогают быстро настроить множество пинов за один раз в секции `setup()`.

#### `regPins(firstPin, lastPin, mode)`
Настраивает непрерывный диапазон пинов от начального до конечного.
* `firstPin` (`uint8_t`): Первый пин в диапазоне.
* `lastPin` (`uint8_t`): Последний пин в диапазоне.
* `mode` (`byte`): Режим работы пина (`INPUT`, `INPUT_PULLUP` или `OUTPUT`).

#### `regPinsArray(pinsArray, arraySize, mode)`
Настраивает массив пинов, которые могут идти в любом произвольном или непоследовательном порядке.
* `pinsArray` (`const uint8_t[]`): Ваш кастомный массив с номерами пинов.
* `arraySize` (`byte`): Общее количество пинов в массиве (можно вычислить через `sizeof(array) / sizeof(array[0])`).
* `mode` (`byte`): Режим работы пина (`INPUT`, `INPUT_PULLUP` или `OUTPUT`).

---

### Класс: `Button`
Разработан специально для тактовых кнопок (моментальных переключателей без физической фиксации). Он определяет точный момент нажатия.

#### `Button(pin, debounceDelay)`
Конструктор для создания объекта кнопки.
* `pin` (`uint8_t`): Номер пина, к которому подключена кнопка.
* `debounceDelay` (`unsigned long`): Время защиты от дребезга контактов в миллисекундах.

#### `isPressed()`
Проверяет, была ли кнопка нажата.
* **Возвращает:** `true` строго один раз за клик (по фронту нажатия). Во всё остальное время возвращает `false`, даже если вы продолжаете удерживать кнопку зажатой.

---

### Класс: `LED`
Используется для управления светодиодами без блокировки выполнения основного кода.

#### `LED(pin)`
Конструктор для создания объекта светодиода на определенном пине.

#### `on()`
Включает светодиод.

#### `off()`
Выключает светодиод.

#### `toggle()`
Инвертирует состояние светодиода (включает, если он был выключен, и наоборот).

#### `blink(interval)`
Асинхронно мигает светодиодом внутри главного цикла `loop()`.
* `interval` (`unsigned long`): Время между состояниями ВКЛ и ВЫКЛ в миллисекундах.

## 📦 Установка

### Способ 1: Через Менеджер библиотек Arduino (Рекомендуемый)
1. Откройте Arduino IDE.
2. Перейдите в **Скетч** -> **Подключить библиотеку** -> **Управлять библиотеками...** (Sketch -> Include Library -> Manage Libraries...).
3. Введите в поиске **SimpleCode** и нажмите **Установить** (Install).

### Способ 2: Ручная установка
1. Скачайте данный репозиторий архивом.
2. Распакуйте и скопируйте папку `SimpleCode` в директорию с вашими библиотеками Arduino (обычно находится в `Документы/Arduino/libraries`).
3. Перезапустите Arduino IDE.

## 📋 Пример использования

```cpp
// Пример: Независимое мигание двумя светодиодами с разной частотой без использования delay().
#include "SimpleCode.h"

// Создаем два объекта светодиодов на разных пинах
LED statusLed(13); // Встроенный светодиод на большинстве плат Arduino
LED alertLed(12);  // Внешний светодиод на пине 12

void setup() {
  // Настройка pinMode() выполняется автоматически внутри классов библиотеки!
}

void loop() {
  // Мигаем статусным светодиодом каждые 500 мс
  statusLed.blink(500);
  
  // Мигаем аварийным светодиодом каждые 150 мс (гораздо быстрее)
  // Оба светодиода мигают абсолютно независимо друг от друга
  alertLed.blink(150);
}
```
